    How it works

    1. Lay one tile next to the land.
    2. Then, if you want, one pawn action: settle, step or attack.
    3. When the last tile is laid, every area of two or more tiles scores for whoever holds it.

    Anarchchess

    The house rules the community plays, collected from r/AnarchyChess, anarchychess.org and the Anarchchess bots. Every rule is a switch: turn it off and it simply does not exist.

    Anarchess

    A reconstruction of the game by Dimitris Grammenos (FORTH). Two to four players share 32 light and 32 dark tiles and grow a landscape; the player with the most pawns in an area of two or more tiles scores it. The published sources describe the components and the scoring but leave several mechanics open, so this build documents each decision rather than guessing quietly.

    About this build

    The engine, the Anarchess rules and the Anarchchess rules running in this page are the same Python files the desktop application uses, executed by Pyodide. Nothing is rewritten for the browser, and after the first visit everything is cached: it works on a plane.
