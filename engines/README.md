# Drop your UCI engines here

Any UCI engine works: Stockfish, Lc0, Komodo, …

* Put the binary in this folder, or install it system-wide and let TALOS
  find it on your `PATH`.
* `Engines ▸ Install Stockfish` downloads a build for your platform and puts
  it here for you.
* `Engines ▸ Manage engines` adds or removes paths by hand.

Nothing in this folder is committed: engine binaries are 100 MB each.
